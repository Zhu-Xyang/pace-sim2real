# ANYmal-D 阻尼比与固有频率分析

## 物理模型

PhysX 求解的二阶系统：

```
I_total · q̈ + (d + kd) · q̇ + kp · q = τ_cmd
```

其中：
- `I_total = Ia + I_link`（armature 惯量 + 下游连杆等效惯量）
- `d` = viscous_friction（关节粘性摩擦系数）
- `kd` = PD 控制器的微分增益
- `kp` = PD 控制器的比例增益

## 参数来源

| 参数 | 值 | 来源 |
|---|---|---|
| kp (stiffness) | 85.0 | env_cfg `stiffness={".*": 85.0}` |
| kd (damping) | 0.6 | env_cfg `damping={".*": 0.6}` |
| d (viscous_friction) | **4.5** | **data_collection.py L61** `damping = torch.tensor([4.5] * ...)`，覆盖 env_cfg 的 0.0 |
| Ia (armature) | 0.1 | data_collection.py L60 `armature = torch.tensor([0.1] * ...)` |
| effort_limit | 89.0 | env_cfg |
| saturation_effort | 140.0 | env_cfg |

> **注意**：env_cfg 中 `viscous_friction={".*": 0.0}`，但 data_collection.py 在采集数据时通过 `write_joint_viscous_friction_coefficient_to_sim(damping=4.5)` 覆盖为 4.5。实际仿真使用的是 d=4.5。

## I_link 计算公式

对关节轴方向单位向量 `a`，每个下游连杆的贡献：

```
I_contrib = I_axis + m · d_perp²
```

其中：
- **I_axis** = `aᵀ · R · I_link · Rᵀ · a`（连杆自身惯量在关节轴方向的投影）
  - `R` = 从关节到该连杆的累积旋转矩阵
  - `I_link` = URDF 中该连杆的 3×3 惯量矩阵
- **d_perp** = `|COM - (COM·a)·a|`（连杆 COM 到关节轴的垂直距离）
  - `COM` = 连杆质心在关节坐标系下的位置
- **m** = 连杆质量

`I_link = Σ I_contrib`（对所有下游连杆求和，不包含父连杆）

## 固有频率与阻尼比公式

```
ω_n = sqrt(kp / I_total) / (2π)   [Hz]

ζ = (d + kd) / (2 · sqrt(kp · I_total))
```

- **设计值**：用 `Ia`（设计者只考虑 armature）
- **实际值**：用 `I_total = Ia + I_link`（PhysX 实际求解用 Ia + I_link）


## 关键发现

1. **d=4.5 是关键阻尼来源**：data_collection.py 设置 viscous_friction=4.5，远大于 kd=0.6。总阻尼 = d + kd = 5.1，其中 d 贡献 88%。

2. **设计阻尼比 ζ_设计 = 0.875**（接近临界阻尼）：因为 d=4.5 很大，设计者意图是让系统接近临界阻尼。

3. **实际阻尼比因关节类型而异**：
   - HAA: ζ=0.39（I_link/Ia=4.16，I_link 大幅拉低 ζ）
   - HFE: ζ=0.45（I_link/Ia=3.39）
   - KFE: ζ=0.80（I_link/Ia=0.27，I_link 小，ζ 接近设计值）

4. **KFE 阻尼最好**（ζ=0.80）：因为 KFE 下游只有小腿和脚，I_link 很小（0.027），I_link/Ia=0.27，实际 ζ 几乎等于设计值。

5. **HAA 阻尼最差**（ζ=0.39）：因为 HAA 下游是整条腿，I_link=0.416，I_link/Ia=4.16，实际 ζ 从 0.875 降到 0.39。

6. **与 S800 对比**：ANYmal 的 d=4.5 提供了大量额外阻尼（S800 的 d=0.1-1.6），所以即使 I_link/Ia 较大，ANYmal 的 ζ 仍比 S800 高（0.39-0.80 vs 0.14-0.93）。
