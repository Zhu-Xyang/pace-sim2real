# S800 关节阻尼比与固有频率计算

## 物理模型

PhysX 求解的二阶系统：

```
I_total · q̈ + (d + kd) · q̇ + kp · q = τ_cmd
```

其中：
- `I_total = Ia + I_link`（armature 惯量 + 下游连杆等效惯量）
- `d` = viscous_friction（电机粘性摩擦系数）
- `kd` = PD 控制器的微分增益
- `kp` = PD 控制器的比例增益

## 计算公式

### I_link（下游连杆等效惯量）

对关节轴方向单位向量 `a`，每个下游连杆的贡献：

```
I_contrib = I_axis + m · d_perp²
```

其中：
- **I_axis** = `aᵀ · R · I_link · Rᵀ · a`（连杆自身惯量在关节轴方向的投影）
  - `R` = 从关节到该连杆的累积旋转矩阵
  - `I_link` = URDF 中该连杆的 3×3 惯量矩阵
- **d_perp** = `|COM - (COM·a)·a|`（连杆 COM 到关节轴的垂直距离）
- **m** = 连杆质量

```
I_link = Σ I_contrib（对所有下游连杆求和）
```

### 固有频率

```
ω_n = sqrt(kp / I_total) / (2π)   [Hz]
```

### 阻尼比

```
ζ = (d + kd) / (2 · sqrt(kp · I_total))
```

  I_total = Ia + I_link
  ω_n = sqrt(kp / I_total) / (2π)   [Hz]

## 关键发现

### 1. 设计值（纯 Ia）的问题

用纯 armature 计算时，设计者认为：
- ω_n 集中在 5–8 Hz（ELBOW_YAW 例外，13.7 Hz）
- ζ 在 0.25–0.93 之间，大部分关节欠阻尼

但 PhysX 实际用 I_total = Ia + I_link，导致：
- ω_n 实际范围 1.05–11.08 Hz，大部分关节 < 3 Hz
- ζ 实际范围 0.056–0.675，13/14 个关节严重欠阻尼（ζ < 0.3）

### 2. I_link/Ia 比值决定偏差程度

| I_link/Ia | 影响程度 | 典型关节 |
|---|---|---|
| > 10× | ω_n 下降 > 70%，ζ 下降 > 70% | HIP_PITCH(15×), HIP_ROLL(31×), KNEE(8×), TORSO(23×), SHOULDER_ROLL(19×) |
| 1–10× | ω_n 下降 30–70%，ζ 下降 30–70% | ANKLE_PITCH(14×), SHOULDER_PITCH(11×), ELBOW_PITCH(11×), WRIST_PITCH(10×) |
| < 1× | 几乎无影响 | HIP_YAW(0.9×), ANKLE_ROLL(0.2×), SHOULDER_YAW(0.2×), ELBOW_YAW(0.5×), WRIST_ROLL(2×) |

### 3. kpkd.py 原始 kp/kd 的设计意图

kpkd.py 注释（L75-108）表明设计目标是：
- ω_n = 5–8 Hz（低增益，在 chirp 带宽内）
- ζ = 1.0（临界阻尼）

但实际计算显示 ζ 设计值远未达到 1.0（最高仅 0.933），说明 kpkd.py 的 kp/kd 值
**并非按注释中的公式严格设计**，可能是经验调参的结果。
